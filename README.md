## 為什麼做這個

市面上有一門由 Scott Young 與 Cal Newport 掛名的三個月線上課程，售價新台幣三千到四千元。
它的結構是好的：專注工作 → 專注生活 → 專注心智。但 Cal Newport 這十年來在自己的 YouTube
頻道、TED、Lex Fridman、Huberman Lab 上，已經把同樣的內容公開講過無數次——而且往往講得更細，
因為那些是聽眾追問出來的。

問題只在於：那些影片是散的，沒有順序、沒有進度、沒有自我檢查，而且**沒有人告訴你哪些主張在
心理學文獻裡其實站不住腳**。

這個專案處理的就是那三件事。

|                  | 官方付費課                 | 這門課                            |
| ---------------- | -------------------------- | --------------------------------- |
| 費用             | NT$2,929–3,929             | 免費                              |
| 內容             | 錄製課程 · 約 6 小時 40 分 | 180 支公開影片 · 30 小時 39 分    |
| 講者             | Scott Young + Cal Newport  | 全部是 Cal Newport 本人的公開影片 |
| 實證查核         | 無                         | 27 則（17 則主張 + 10 類做法），附 Crossref DOI |
| 對自己不利的證據 | 無                         | 照實寫，5 題標為「證據互斥」      |
| 授權關係         | 官方                       | **無，純第三方策展**              |

## 課程長什麼樣

12 章、60 個單元、180 支影片，分三篇：

| 篇               | 章                                                                           |
| ---------------- | ---------------------------------------------------------------------------- |
| **一　專注工作** | 專注為何是稀缺資源 · 深度工作的操作參數 · 排程儀式與一日節奏 · 任務與計畫系統 |
| **二　專注生活** | 注意力經濟 · 數位斷捨離 · 獨處無聊與思考 · 高品質休閒與真實連結               |
| **三　專注心智** | 慢速生產力 · 過載訊息與工作流程 · 職涯資本 · 深度心智與深度人生               |

每個單元固定三個部分：

1. **先自己檢查一次** — 一個今天就能做的檢查（算一次真正的深度時數、翻一次螢幕使用時間、
   數一數手上同時進行幾個專案）。沒檢查過，後面的做法只是知識。
2. **一支主課 + 兩支延伸片段** — 主課講原理，延伸片段分「原理／做法／實戰問答」三類。
3. **實證註記** — 這個主張在文獻裡站得住腳嗎，附 DOI。

## 查核結果沒有很好看，而這正是重點

27 則查核（17 則主張 + 10 類做法）裡有 5 則被判為 `contested`，包括 Cal Newport 最有名的幾個主張：

- **社群媒體在傷害你** — 三份大型資料集、超過三十五萬名青少年的分析顯示，數位科技使用只解釋
  約 **0.4%** 的福祉變異，與戴眼鏡、吃馬鈴薯同一量級。隨機停用實驗確實測到改善，但效果約
  **0.09 個標準差**，而且伴隨新聞知識下降。
- **多工讓你的注意力變差** — 2009 年那篇被引用到爛的 PNAS 研究是橫斷面設計；十年後的統合分析
  把效果縮到接近零。
- **刻意練習決定專家表現** — 統合分析顯示它只解釋遊戲約 21%、音樂約 18%、**專業領域約 1%** 的
  表現變異，遠低於一萬小時說法給人的印象。
- **斷捨離一定優於節制** — 兩種做法各自都有隨機試驗支持，但**從來沒有人把它們放進同一個試驗
  比較過**。這是課程裡最常被當成鐵律、卻最沒有直接證據的一條。
- **「手機在旁邊就變笨」** — 原始研究流傳極廣，統合分析後效果非常小、與發表偏誤難以區分。

站得住腳的部分也照實寫：**限制檢查信箱的頻率**（隨機試驗，顯著降低壓力）與**主動回想**
（數十年反覆驗證）拿到 `strong`。

全部結論與原始文獻連結都在網站的〈這門課的立場〉頁。

## 這是怎麼做出來的

用 [curate-course](https://github.com/htlin222/curate-course) 框架——一個 topic-agnostic 的
課程策展系統。你只需要動 `course/`，其餘都是框架。

```
course/
├── course.config.json   站台設定、章節、配額、所有 UI 文案
├── data/                策展資料（12 章 + 影片中繼資料 + 實證）
├── taxonomy/            主題詞彙（topics 分面、practices 分類）
└── assets/og.png        社群預覽圖
```

三條不可退讓的規則：

1. **策展不是生成。** 180 個 video ID 全部取自實際的 YouTube 搜尋結果，沒有一個是憑記憶拼湊的。
2. **不信任任何上游宣稱**，包括自己剛才說已經驗證過的。交付前一定跑 `make audit` 與 `make verify`。
3. **誠實比好看重要。** 查證結果對課程不利就照實寫，標成 `contested`。

```bash
make build     # course/ → dist/，配額不符直接失敗
make audit     # 離線稽核：設定檔、配額、影片長度、實證深度
make verify    # 重驗每個 YouTube 連結與每個 DOI（打真實 API）
make serve     # http://localhost:8899
make deploy    # 部署到 Cloudflare Pages
```

### 交付時的實際數字

```
稽核     0 錯誤（1 個警告：60 個單元中 14 個有單元層級查核，其餘掛在做法類別上）
連結     180 / 180 有效（100.0%）
引用     75 / 75 通過，34 個不重複 DOI 全部在 Crossref 存在且標題相符
影片     180 個欄位、180 支不重複（零重複使用）、30 小時 39 分
```

## 對框架本身的一個修正

`src/build/audit.py` 原本只認 PMID，人文社科走 Crossref 的引用會被整批判為「格式不合法」——
但 `verify_refs.py` 明明兩種都驗。已補上 `valid_ref()`：PMID 或 DOI 擇一合法即通過。
